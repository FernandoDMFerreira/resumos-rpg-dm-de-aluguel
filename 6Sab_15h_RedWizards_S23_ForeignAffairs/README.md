## Como publicar no GitHub Pages

1. Extraia este ZIP no computador.
2. No repositório `resumos-rpg-dm-de-aluguel`, envie as pastas e arquivos extraídos.
3. O arquivo da sessão precisa se chamar exatamente `index.html` dentro da pasta da sessão.
4. Depois do commit, aguarde alguns minutos o GitHub Pages publicar.
